# Tshwane Bus Transit Monorepo

This repository contains a complete mobile and backend application for Tshwane Bus Transit, enabling commuters in Pretoria to search routes, buy tickets, track buses, and manage an e-wallet.

Directory structure:

```
tshwane-bus-transit/
├── mobile/              # React Native Expo app
├── server/              # Node.js Express backend
├── shared/              # Shared utilities (theme, types)
└── docs/                # Documentation
```

See `docs/SETUP.md` for local setup and `docs/API.md` for full API docs.
